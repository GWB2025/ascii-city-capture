ASCII CITY CAPTURE 1.2.1 — browser fetch repair, 29 October 2026

The version selector stored Window.fetch as an instance property and invoked it
with the selector instance as its receiver. Chrome rejected this with the exact
reported Illegal invocation error. The default request function now calls
fetch through globalThis so the browser receives the correct global object.

A new regression test first reproduced the exact error against 1.2.0, then
passed after the repair. It enforces the native browser receiver requirement
and checks both catalogue GET and version-selection POST requests. Node's native
fetch and the earlier arrow-function mocks did not enforce that requirement.

55 tests passed for this patch: 35 Python and 20 JavaScript. The five jsdom UI
tests now also have a stricter fetch mock, but were not rerun for this patch.
City rendering, adapter generation and export geometry are unchanged. The
three city replays documented below are the previous 1.2.0 validation.

Native bundle self-test, moved-bundle payload validation, ad-hoc signature
verification and archive integrity checks passed. Both bundled releases are
included. The complete normal Chrome launch remains unverified in this session.

LIMITS

The replay is an integration test, not a live Chrome test. Local web-server
binding was denied by the development sandbox. Browser policy also denied
file-URL preview navigation. No attempt was made to bypass those restrictions.
The double-click launch and complete browser interaction need a smoke test in
the normal Mac session. Individual transport journeys and music were not tested.
No USB connection or physical plotting was performed.

The print test used Courier New outlines with previously recorded coordinates.
The live adapter explicitly loads the chosen local font before the city starts,
so that live character spacing and exported outlines use the same font.
Rasterisation/antialiasing may differ between Canvas, SVG viewers and printers.
Pen output is an outline interpretation: translucent effects are solid outlines,
very faint draws below 1% opacity are omitted, and no shading or background
strokes are added. Original character identities are retained in SVG metadata.
